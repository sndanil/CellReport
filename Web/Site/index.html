CellReport

CellReport это табличный генератор отчетов для платформы Microsoft .Net, это функциональный аналог генератора отчетов платформы 1С, который прекрасно зарекомендовал себя, как один из лучших генераторов отчетов для бизнес приложений. Данный генератор отчетов прекрасно подходит для формирования печатных форм документов и интерактивных отчетов.

Генератор отчетов реализован в виде подключаемой сборки для WinForms приложений платформы Microsoft .Net Framework 3.5 SP1. В качестве шаблона для формирования отчета, используются XML данные. На данный момент продукт находится в стади и альфа версии. Скачать демонстрацию

Представление и интерактивность

Основное преимущество данного генератора отчетов заключается в том, что он позволяет представить сформированный отчет пользователю без разбиения на страницы и без отображения колонтитулов (номер страницы, название отчета и т.д.). Это позволяет пользователю сосредоточиться на представленной ему информации. Колонтитулы будут отображены уже при печати отчета или при предварительном просмотре перед печатью. А так же есть возможость обработки действий пользователя (например двойной щелчек мыши на определенной ячейке), что добавляет интерактивности при работе с данными отчета. Например позволяет открыть дополнительное окно информации о представленном в отчете объекте.

Различные виды графиков, изображения и штрихкоды

Имеется возможность использования графиков. Для рендеринга графиков используется набор компонент Microsoft Chart Controls for Microsoft .NET Framework. Шаблон отчета может содержать информацию о изображении. Источником изображения могут быть как ресурсы самого шаблона (т.е. файл шаблона отчета содержит изображение), так и файл на диске или ссылка по протоколу HTTP. Так же есть возможность печати штрихкодов различного формата. Галерея

Печатные формы документов

Так как основная масса форм документов доступна в сети интернет в виде документов для Microsoft Excel, то они прекрасно конвертируются в структуру табличного генератора отчетов (формат файлов "Таблица XML 2003"). Кроме того генератор отчетов позволяет при печати документа автоматически подсчитывать суммы отображенных на странице позиций и выводить их в итоге страницы. Галерея

Поиск и закладки

В сформированном отчете есть функция поиска, а так же возможно формирование так называемых "закладок", которые сформируют древовидную структуру, что позволит пользователям осуществлять быструю навигацию в отчете. Галерея

Предварительный просмотр

Имеется возможность предварительногопросмотра сформированного отчета перед отправкой на печать. По результатам просмотра которого пользователь может при печаи выбрать только необходимые ему страницы. Галерея

Экспорт в Excel

Геренатор отчетов предоставляет возможность экспортировать сформированный отчет в формат Microsoft Excel 2007. Для дальнейшего анализа данных в программах Microsoft Excel или OpenOffice Calc. Экспорт не требует установленного Microsoft Excel на компьютере пользователя.

Mono / WPF / HTML

Данный генератор отчетов позволяет использовать основные свои возможности в операционных системах отличных от Microsoft Windows при помощи кроссплатформеной реализации .Net от проекта Mono. Галерея

Также есть базовая поддержка работы в WPF (Windows Presentation Foundation). На данный момент редактор шаблонов выполнен в виде WPF приложения для Microsoft .Net Framework 4.0. А так же планируется создание возможности предоставлять сформированные данные в виде HTML страницы.
